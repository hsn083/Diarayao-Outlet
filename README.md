# Diaraya Outlet - Premium Abaya & Modest Fashion E-Commerce Store 🌸

A professional full-stack online modest fashion store built with Next.js, TypeScript, TailwindCSS, MongoDB, and modern web technologies for selling premium abayas, hijabs, and elegant modest wear.

Diaraya Outlet provides a complete luxury shopping experience with customer accounts, secure authentication, product management, shopping cart, checkout system, order management, customer reviews, wishlist system, coupon management, payment verification, and a powerful admin dashboard.

# 🔧 Environment Variables

Create `.env.local` file:

```env
# MongoDB Configuration
MONGODB_URI=your_mongodb_connection_string


# Authentication
JWT_SECRET=your_jwt_secret_key


# Cloudinary Configuration
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret


# Email Configuration
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_app_password


# Application URL
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
